# Voyage Alpha Vision

Voyage Alpha is the operating system for Odyssey Group of Creative Studios.
Its purpose is not to manage projects.
Its purpose is to help people make better creative and business decisions.
Every feature in Voyage must satisfy at least one of these principles:

- Increase clarity.
- Reduce friction.
- Preserve institutional knowledge.
- Improve decision quality.
- Help Odyssey create sustainable value.

If a feature does not satisfy one of these principles, it does not belong in Voyage.
